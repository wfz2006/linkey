# 极速 QQ GUI 重设计 · 夜幕流光液态玻璃版 — 设计文档

> 日期：2026-08-17
> 状态：已获用户确认
> 范围：`public/` 前端全量视觉重设计（零依赖原则不变）

---

## 1. 设计目标与公式

用户理念：**模仿原版 QQ + iOS 液态玻璃（Liquid Glass）设计语言，炫酷精致**。

```
新版 GUI = 原版 QQ 骨架与细节神韵（NTQQ 布局 + 经典元素回归）
         + 液态玻璃质感（blur 16-18px · saturate 1.4 · 镜面高光描边）
         + visionOS 级动效（视差 · 光泽扫过 · 液态指示器 · 涟漪）
         深色夜幕底色 · 全界面一次到位
```

## 2. 已确认的五项关键决策

| 决策点 | 选择 | 含义 |
|---|---|---|
| 底色方向 | B · 夜幕流光 | 深色为主，现状进化 |
| QQ 还原深度 | B · 细节级 | NTQQ 三栏骨架 + 经典细节（气泡造型/圆角矩形头像/角标红点/滑入资料卡/特别关心分组） |
| 玻璃浓度 | B · 液态玻璃 | blur 16-18px + saturate(1.4) + 镜面高光描边 |
| 改造范围 | 全选 | 登录/工作台/资料卡联系人/空间/弹窗菜单移动端 |
| 动效档位 | C · 极致 | 视差 + 光泽扫过 + 涟漪 + 3D 翻转 + 呼吸辉光，尊重 prefers-reduced-motion |

## 3. 设计 Token 体系

### 3.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg-canvas` | `#070B14` | 全局画布 |
| 背景光斑 | 蓝 `#0a2a5e`（左上）+ 紫 `#3d1a6e`（右下）径向渐变 | 环境氛围，支持鼠标视差 |
| `--qq-blue` | `#12B7F5` | QQ 官方品牌蓝起点 |
| `--gradient-brand` | `linear-gradient(135deg, #12B7F5, #0D8CE0)` | 主按钮 / 我方气泡 / 选中态 |
| 玻璃面 | `rgba(255,255,255,0.08)` + `backdrop-filter: blur(18px) saturate(1.4)` | 列表项 / 卡片 / 弹窗 |
| 镜面高光 | `inset 0 1px 1px rgba(255,255,255,0.22)` 顶缘亮线 | 所有玻璃层标配 |
| 悬浮玻璃 | 玻璃面 + 抬升阴影 + 双色边缘微光 | hover / 资料卡 / 弹窗 |
| 文字 | 主 `#FFFFFF` / 次 `#CBD5E1` / 弱 `#8FA3BA` | 三级层次 |
| 状态 | 在线 `#10B981` / 离开 `#F59E0B` / 离线 `#64748B` | 不变 |

### 3.2 几何

- 头像：**圆角矩形** `border-radius: 11px`（NTQQ 风格，替换纯圆），仅导航头像保留胶囊
- 气泡：我的 `16px 16px 4px 16px` 渐变蓝 + 小尖角；对方 `16px 16px 16px 4px` 玻璃白
- 三栏：54px 导航 / 288px 列表 / 弹性聊天区
- 未读红点：绝对定位于**头像左下角**，带 1.5px 画布色描边

## 4. 分界面规格

### 4.1 登录页
- 中央液态玻璃大卡片（max-width 400px），企鹅 Logo 辉光呼吸（2.4s）
- 输入框聚焦：玻璃光泽斜向扫过（伪元素渐变 translateY 过渡 600ms）
- 登录/注册 Tab：底部液态指示器滑动（absolute 胶囊 transform 过渡）
- 快捷账号：玻璃小胶囊横排

### 4.2 三栏工作台
- **左栏 54px**：顶部头像（圆角矩形 + 在线角标小圆点）；消息/联系人/空间图标按钮，激活态为液态胶囊背景（指示器在图标切换时平滑滑动）；底部静音/退出
- **中栏 288px**：顶部搜索玻璃胶囊（聚焦时边框亮蓝）；会话列表项 = 圆角矩形头像 + 昵称（备注优先）+ 摘要单行省略 + 时间右上角小字 + 头像左下未读红点（99+ 封顶）；置顶会话背景 `rgba(18,183,245,0.08)` + 左缘 2px 蓝条；hover 玻璃抬升
- **右栏聊天区**：
  - 顶部玻璃条：圆角矩形头像 + 名称 + 在线状态文字（在线时绿点呼吸）+ 右侧搜索/群管理/戳一戳图标
  - 群公告条：玻璃浅蓝横条 + 📢 图标，可关闭
  - 消息气泡：QQ 经典造型（见 3.2）；头像在气泡外侧；引用回复 = 气泡内嵌小玻璃片（左侧 2px 竖线 + 原文单行省略）；图片消息圆角 12px 悬浮放大 hover；文件消息玻璃卡片式；撤回/系统消息 = 居中玻璃小胶囊灰字
  - 输入区：悬浮玻璃胶囊容器，内含表情/图片/文件/戳一戳 + 多行输入 + 渐变发送球（hover 时光泽扫过）；输入框上方浮出引用回复条
  - 正在输入提示：对方头像 + 三点跳动

### 4.3 资料卡与联系人
- 资料卡：先顶部滑入（translateY -100% → 0，QQ 上线提醒式）后居中定格；Hero 流光背景（保留 aurora/cyberpunk/sunset/ocean/sakura 五主题）+ 底部玻璃信息区；徽章墙为玻璃小徽章横排；亲密度显示为温度计进度条（0-99°C 渐变红黄）；操作按钮三枚玻璃按钮
- 好友列表：QQ 分组折叠结构——分组头（▶ 旋转箭头 + 分组名 + 计数灰字），"特别关心"分组头蓝色字 + ❤️；成员行与中栏列表项同构
- 好友申请弹窗：玻璃列表，每行头像 + 留言 + 同意（品牌蓝）/拒绝（灰玻璃）按钮
- 群成员管理：角色徽章（👑 群主金 / 管理员蓝 / 成员灰玻璃）+ 踢人/禁言操作按钮

### 4.4 QQ 空间
- Hero 头部：流光主题渐变（不动）+ 叠加玻璃顶栏（昵称 + 黄钻徽章 + 访客数）
- Tab 栏：液态指示器滑动（说说/相册/留言板/个人档）
- 说说卡片：玻璃卡 + 圆角矩形头像 + 昵称 + 等级图标 + 时间；图片九宫格；操作条 = 点赞（点击 ❤️ scale 弹出动画 + 已赞红色）+ 评论数 + 删除（作者可见）
- 评论：内嵌玻璃小片列表 + 底部评论输入胶囊
- 相册：瀑布流两列（移动端）/三列（桌面），hover 抬升，灯箱打开时背景 blur 加深
- 留言板：玻璃卡片流 + 输入胶囊

### 4.5 弹窗/菜单/移动端
- 模态统一：玻璃面板（blur 24px 高档）+ 背景加深 + scale(0.92)→1 弹入 220ms cubic-bezier(0.34,1.56,0.64,1)
- 右键菜单：小玻璃浮层，hover 项光泽扫过
- Toast：顶部滑入玻璃胶囊，2.5s 自动滑出
- 移动端 <768px：单列栈 + 底部玻璃 Tab 栏（图标 + 液态指示器）；列表↔聊天切换 = 3D rotateY 翻转（perspective 1200px）；`100dvh` 键盘避让保留

## 5. 动效清单（C 档）与性能护栏

| 动效 | 触发点 | 实现 | 降级 |
|---|---|---|---|
| 鼠标视差 | 全局 | 光斑 `background-position` rAF 缓动（lerp 0.06） | reduced-motion 关闭；低端机（见 5.2）自动关 |
| 光泽扫过 | 玻璃层 hover | 伪元素斜向高光 translateY 600ms | reduced-motion 关闭 |
| 液态指示器 | 导航/Tab 切换 | absolute 胶囊 transform 320ms spring | 降级为 opacity |
| 气泡弹入 | 新消息 | scale(0.9)→1 + translateY(8px)→0 spring | 降级为 fade |
| 消息涟漪 | 同会话 500ms 内连发 | 气泡外圈 box-shadow 扩散一次 | 关闭 |
| 状态呼吸 | 在线绿点 | box-shadow 呼吸 2.4s infinite | 关闭 |
| Logo 辉光 | 登录页 | drop-shadow 呼吸 2.4s | 关闭 |
| 页面 3D 翻转 | 移动端列表↔聊天 | rotateY(±8deg) + perspective | 降级为 slide |
| ❤️ 弹出 | 点赞点击 | scale 0→1.3→1 keyframes | 关闭 |

### 5.1 prefers-reduced-motion
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

### 5.2 低端机自动降级
JS 采样首 3 秒平均帧率 < 45fps → body 加 `.perf-low` class：关闭视差与光泽扫过（opacity 直切）。

### 5.3 性能护栏
- 视差只动 `transform`/`background-position`（后者仅两个光斑元素）
- 会话列表项**不用** backdrop-filter（用半透明纯色模拟玻璃，避免滚动长列表掉帧）；真正的 backdrop-filter 只用于弹窗/顶栏/输入区等少量悬浮层
- `will-change` 仅限动效进行中的元素

## 6. 文件改动边界

| 文件 | 改动 |

| `public/css/style.css` | **全量重写**（设计 token + 组件层 + 动效 keyframes），保留既有 class 命名尽量兼容 |

## 7. 验收标准

1. 桌面 Chrome/Edge + 手机浏览器（同局域网）目检全部 6 大区域
2. `prefers-reduced-motion: reduce` 下无持续动画
3. 移动端 375px 宽度布局不破、键盘弹出输入框不被遮挡
4. 会话列表 200+ 项滚动无明显掉帧（性能护栏生效证据）
5. `node --test tests/*.test.js` 29/29 通过（前端纯视觉改动不影响后端）
6. 旧功能全部可用：发消息/撤回/引用/好友全流程/空间互动/群管理
