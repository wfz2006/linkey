📖 数据库恢复简易手册 (Disaster Recovery)

  1. 在上方【仪表盘】中点击【⏹️ 停止主服务】（或执行 admin-stop.cmd）；
  2. 删除 d:\software\qq_chat.db 以及伴随的 -wal 和 -shm 文件（若存在）；
  3. 将所需时点的备份文件下载或直接复制并重命名为 d:\software\qq_chat.db；
  4. 在控制台中点击【▶️ 启动主服务】，即可回到该备份时点的完整状态！
